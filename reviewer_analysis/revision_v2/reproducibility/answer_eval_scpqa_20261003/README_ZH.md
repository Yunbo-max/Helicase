## 计算和已知范围

每题计算 P=m/Np、R=m/Nr、F1=2m/(Np+Nr)，最大一对一匹配。先平均同题两个评委，再分别宏平均 P、R、F1；10,000 次 bootstrap 以 20 个问题为单位，未做多重比较校正。只有每方法一份存档报告，不代表独立 agent 重复实验。
两位评委对 517 个预测项的二元匹配状态一致率为 98.65%，Cohen κ=0.9639。一致性不等于人类真值正确率。

**抽取范围限制：** 原 V4 冻结规则排除了部分“没有公开确认”的回答，而 scpqa 有多题正以这种回答为参考。Helicase 在 Q63/Q65/Q68/Q69/Q72/Q75 均为零个保留预测项；Q68 本身为未回答框架，其他题需结合已保存的排除记录理解。全部方法使用同一冻结规则和零预测计零分规则，不删题、不补写答案。本轮完成固定预测项匹配，不宣称已经解决这种 reference 与抽取规则的适配问题。
reference 卡片由执行 agent 按文字答案和题目粒度维护，不是独立专家标注。用户确认文件版本不等于来源独立性已验证。参考外未匹配项不自动等于现实事实错误，答案匹配也不代表引用支持。
服务端模型快照未独立核验；本报告使用实际请求型号。所有完整匹配理由及逐题命中／遗漏／额外项留在私有目录。

七项匹配状态分歧已检查，涉及保留态度、产品／公司身份及计划／实际表述。原始双评委判断均保留，没有按排名选择某位评委或事后改分，见[分歧说明](disagreement_review.json)。
